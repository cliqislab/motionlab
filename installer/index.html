M MOTIONLAB SETUP

MotionLab Kit / Instalação guiada

Seu estúdio de vídeos, passo a passo.

Vamos preparar o computador e abrir o MotionLab no VS Code. Você acompanha todas as etapas.

1. Verificar seu computador

Diagnóstico

Os programas já encontrados serão preservados. Não instalaremos versões duplicadas.

Verificando...

2. Instalar o que falta

Sua autorização

O MotionLab usa Homebrew (Mac) ou winget (Windows) para instalar Node.js, Python, FFmpeg e VS Code. Podem surgir pedidos de confirmação do sistema.

Verificando programas...

O Claude Code será configurado em uma etapa separada e requer uma conta própria.

3. Preparar os arquivos do MotionLab

Projeto

O kit será copiado para Documentos/MotionLab Kit. Arquivos e vídeos existentes não serão apagados.

A verificação analisa o ambiente sem iniciar uma renderização completa. O preparo inicial pode levar alguns minutos.

4. Configurar voz com Gemini (opcional)

Narração por IA

Quer que seus vídeos tenham narração com vozes do Gemini? Você pode configurar agora ou pular esta etapa.

Como criar sua chave:
  1. Clique em Abrir Google AI Studio e entre com sua conta Google.
  2. Na página API Keys, clique em Create API key (Criar chave de API).
  3. Escolha ou crie um projeto e copie a chave gerada.
  4. Volte ao MotionLab, cole a chave abaixo e clique em Salvar chave.

Verificando...

A chave fica somente no arquivo Documentos/MotionLab Kit/.env deste computador. Não aparece nos logs e não é enviada ao GitHub. Não compartilhe a chave; o uso da API pode estar sujeito a limites e cobrança do Google.

A configuração permite usar a voz do Gemini quando você pedir narração no Claude. Você também pode criar vídeos sem chave ou usar a voz gratuita de teste.

5. Abrir VS Code e configurar Claude

Criação por conversa

Abra o projeto no VS Code. No terminal integrado, execute claude e entre na sua conta, caso solicitado.

O MotionLab abre o VS Code com a pasta correta. Por segurança e compatibilidade, você inicia o terminal com Terminal → Novo Terminal e digita claude.

Se o Claude Code não estiver instalado, consulte o guia oficial. Depois, clique em “Verificar novamente” na etapa 1.

6. Crie seu primeiro vídeo

Pronto!
