Prontas para animar.

Prompts de comerciais premium com direção de arte, ritmo, referências e aprovação antes do render. Copie, personalize os campos entre colchetes e cole no Claude Code, dentro do projeto MotionLab.

Como usar: abra o VS Code pelo instalador, vá em Terminal → Novo Terminal, digite claude e cole um prompt. O comando principal é /motion. O Brag original é opcional e não acompanha este instalador. Modelos 3D reais, edição avançada e voz dependem dos recursos instalados.
